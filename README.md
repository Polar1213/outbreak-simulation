# OUTBREAK — Epidemic Management Simulation

An interactive, 30-day epidemic-management simulation built in Python using CMU Graphics for a Carnegie Mellon University programming project.

## Overview

Manage an outbreak in a simulated city of **50,000 residents**. The game features an **8×8 city map**, neighborhood-level infections, hospitals, businesses, and player interventions. The objective is to reduce deaths while balancing limited funds and healthcare capacity.

## Features

- Day-by-day infection transmission and disease progression across connected districts
- Neighborhood testing, vaccination, and quarantine
- Hospital admissions, capacity upgrades, and mortality effects from overcrowding
- Business upgrades and income management
- Interactive map with infection severity indicators and end-of-game results

## Running locally

1. Install Python 3.
2. Install the graphics dependency:

   ```bash
   python -m pip install -r requirements.txt
   ```

3. Run the game:

   ```bash
   python outbreak.py
   ```

The original course project also supported a locally bundled `cmu_graphics-version-2.0.3` directory; the source checks for that folder and otherwise imports `cmu_graphics` from your Python environment.

**Note:** If the graphics package cannot be installed or the game fails to start, use the CMU Graphics version provided by the course, placed alongside `outbreak.py` in a folder named `cmu_graphics-version-2.0.3`. Verify that the package's `cmu_graphics` module is inside that folder.

## Technical details

The game uses CMU Graphics event handlers for input and drawing. Shared game state is stored on the `app` object, with parallel lists representing the 64 map tiles. Simulation updates advance infections, hospital outcomes, and reported cases across successive days.

## Scope

This is an **educational simulation**, not a calibrated epidemiological model or medical decision-support tool. Outcomes are generated by game mechanics and should not be interpreted as real-world disease forecasts.
